# DOCX 导出

在工具栏中选择 **导出 → Word 文档** 即可下载 `.docx` 文件。经典工具栏、功能区工具栏和只读模式均可使用，文件名默认取文档标题，空标题使用“未命名文档”。文件名中的非法字符会被替换。

导出在浏览器中完成，无需转换服务器。`docx` 转换模块在首次导出时按需加载；图片会从文档已有的资源地址读取并嵌入文件。

## 调用方法

通过组件的 `ref` 调用，在编辑器创建完成后使用：

```js
// 生成并下载文件，返回 Promise<Blob>。
await editorRef.value.exportDocx()

// 指定文件名，.docx 后缀可省略。
await editorRef.value.exportDocx('工作周报.docx')

// 只生成 Blob，便于自行上传、保存或处理。
const blob = await editorRef.value.getDocx()
```

`getDocx()` 和 `exportDocx()` 始终包含正文及可见的页眉页脚，也包含正在编辑且尚未同步到页面配置的页眉页脚内容。Web 视图使用保存的页眉页脚配置。导出不修改文档内容、选区、缩放、只读状态和撤销记录。

`exportDocx()` 执行期间显示居中的“正在导出…”弹窗，遮罩阻止重复点击，按钮保持原来的文字和外观。弹窗在成功或失败后自动关闭，无法通过 Esc、点击遮罩或关闭按钮提前关闭。同一个编辑器再次调用 `exportDocx()` 会复用当前任务，避免重复下载；`getDocx()` 只生成 Blob，不显示弹窗。

图片不可访问、格式不受浏览器支持或生成失败时，方法会 reject；工具栏会显示错误提示，以便重试。跨域图片服务器需要允许浏览器通过 CORS 读取资源。

沿用已有的菜单开关，可以隐藏 DOCX 按钮：

```js
const options = {
  disableExtensions: ['export-docx'],
}
```

## 格式支持

文档默认使用宋体（SimSun），正文、标题及页眉页脚在编辑器和 DOCX 中使用相同的默认字体。手动设置的其他字体会保留，代码块继续使用等宽字体。可通过 CSS 变量 `--umo-content-font-family` 自定义文档默认字体，DOCX 会读取该设置；字体本身不会嵌入文件。

| 内容                                 | 导出结果                                                       |
| ------------------------------------ | -------------------------------------------------------------- |
| 段落、1–6 级标题                     | 可编辑的 Word 段落和标题样式                                   |
| 粗体、斜体、下划线、删除线、上下标   | 对应的文字格式                                                 |
| 字体、字号、文字颜色、背景色、字间距 | 对应的 Word 文字属性                                           |
| 对齐、首行缩进、行距、段前段后间距   | 对应的段落属性                                                 |
| 有序列表、无序列表                   | Word 列表编号，保留嵌套、编号样式和起始值                      |
| 待办事项、选项框                     | 保留勾选状态和文字                                             |
| 表格                                 | 保留列宽、横向与纵向合并、表头、底色和对齐                     |
| 图片、行内图片                       | 嵌入文件，保留尺寸、翻转、旋转和显示的图注；超出页面时等比缩小 |
| SVG、WebP 等图片                     | 转换为 PNG 后嵌入；PNG、JPEG、GIF、BMP 保留原始图片数据        |
| 引用、代码块、提示块                 | 保留文字和基本段落样式                                         |
| 分栏                                 | 转为无边框表格，保留各栏文字                                   |
| 超链接、附件、音视频、嵌入网页       | 保留文字与可访问的链接                                         |
| 日期、提及、标签                     | 保留显示文字                                                   |
| 脚注                                 | Word 原生脚注及其引用                                          |
| 目录                                 | Word 目录域，可在 Word 中更新目录                              |
| 纸张、横竖向、页边距、页面底色       | 使用当前页面设置                                               |
| 页眉、页脚、页码、总页数             | Word 页眉页脚与动态 PAGE / NUMPAGES 域，保留页码格式           |
| 手动分页符                           | Word 分页符，连续分页符保留空白页                              |

自动分页由 Word 重新计算，页数和换行会随字体、Word/WPS 版本及排版引擎变化。页码和目录设置为打开时更新，也可在 Word 中手动更新域。

公式目前保留 LaTeX 文字；动态交互图表和自定义节点保留可取得的文字或链接，未提供文字的节点显示类型名称。浮动图片和文本框按正文顺序输出。水印、编辑器控件和自定义 CSS 不会完整还原。需要固定页面外观时可使用已有的 PDF 导出。

## 验证

```sh
npm run test:docx
npm run build
```

浏览器测试覆盖两种工具栏的实际文件下载、只读导出、进度弹窗与重复导出、默认宋体与手动设置的字体、格式与列表、合并表格、图片转换、页眉页脚、动态页码、Web 视图、空文档和失败后重试，并检查生成文件的 XML 与内部资源引用。
